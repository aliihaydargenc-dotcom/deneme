- CSV delimiter/encoding assistant

- Column rename / select / reorder
- Multi-file merge

- DuckDB-WASM
- SQL workspace
- Parquet import/export
- Pivot builder
- Chart preview

## v0.4 — Workflow Engine
- Drag-drop workflow canvas
- Batch files
- Saved templates
- Workflow import/export JSON

## v0.5 — AI Layer
- Natural language to tool/workflow
- Explain dirty columns
- Formula/SQL generation
- Local model + optional cloud model adapters
